# 🌦️ Mausam4U — Real-Time Weather Forecast

A fully responsive weather forecasting web app built with vanilla HTML, CSS, and JavaScript. Search any city, state, or country — or use your current location — to get live weather conditions and a 5-day forecast.

## Features

- 🔍 Search weather by city / state / country
- 📍 "Use my location" — auto-detect weather via geolocation
- 🌡️ Toggle between °C and °F
- 🌗 Light/dark theme toggle
- 📊 Current stats: humidity, wind, pressure, sunrise & sunset
- 📅 5-day / 3-hour interval forecast

## Tech Stack

- HTML5, CSS3, JavaScript (vanilla, no frameworks)
- Weather data via a public weather API

## Getting Started

1. Clone the repository:
```bash
   git clone https://github.com/dev-aryan24/Mausam4U-Weather-Web-Application.git
```
2. Open `index.html` in your browser — no build step required.
3. If the app uses an API key, add yours in `app.js` before running.
